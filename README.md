# 绘灵（ST-HuiLing-Image）

SillyTavern（酒馆）剧情自动配图插件。核心目标只有一个：**让同一个角色在跨楼层、跨场景的生图里不换人**。

> 本插件面向成人向角色扮演场景。使用者需自行确认所在地区法律与所用平台的服务条款。

---

## 它解决什么问题

通用生图插件把「角色长什么样」交给每一楼的提示词去描述，结果是：这一楼黑长直加过膝袜，下一楼发色变了、袜子丢了、胸型换了。绘灵把外貌与服装拆成**资产**，只允许按规则变化：

| 规则 | 做法 |
|---|---|
| 服装是资产，不是描述 | 款式在库里注册，正文只引用，不接受自由改写 |
| 变化按位置门控 | 只有剧情允许的部位才会被改写，其余保持基准 |
| AI 输出之后再验一遍 | 模型返回的服装字段会回写复验，不合规的整条丢弃 |
| 人设主权锁 | 发型、发色、体型、五官只沿用你给定的基准，插件不"合理化" |

---

## 主要功能

- **三条生图渠道**：ComfyUI（工作流参数全透传）、NovelAI、OpenAI 兼容图像接口。
- **角色档案**：静态锚点（外貌、五官、体型）与动态状态（服装、情绪、裸露程度）分开存储，按**聊天**隔离，不同对话互不污染。
- **楼层结果缓存**：按 `卡名_chatId|楼号|swipe` 记录，重 roll 不会串图。
- **图库与归档**：历史浏览、分类、批量选择与删除；出图可自动归档到本地目录。
- **排版**：支持单图排版与漫画页版式，格框与气泡坐标由代码计算，不交给模型估。
- **独立窗口界面**：七个页签（后端、角色、出词、排版、图库、诊断、设置），可收起成窄条。

## 安装

要求 **SillyTavern ≥ 1.12.13**。

**方式一：扩展面板安装（推荐）**

1. 打开酒馆 → 顶部「扩展」（插头图标）→ **Install Extension**
2. 填入本仓库地址：`https://github.com/zw523164/ST-HuiLing-Image`
3. 安装完成后**完全重启酒馆**（关掉窗口或启动器点停止，不是刷新页面）

> 插件代码不会热加载。换版本后必须完全退出再启动，否则跑的还是旧代码。

**方式二：手动放置**

把整个文件夹放到 `SillyTavern/data/<你的用户>/extensions/` 或
`SillyTavern/public/scripts/extensions/third-party/`，重启酒馆。

---

## 首次配置（四步）

1. **选生图后端** —— ComfyUI / NovelAI / OpenAI 兼容接口，填地址与凭据。
2. **选模型与 CLIP**（ComfyUI 渠道）—— 从后端已安装的列表里选。
3. **粘工作流** —— 导入 ComfyUI 导出的 API 格式工作流 JSON，插件会自动识别可替换的参数节点。
4. **建档** —— 打开角色档案页，为当前角色卡填写外貌基准与初始服装。

---

## 正文里的 tag

在楼层正文里用简短的方括号 tag 触发配图，可指定角色、场景与镜头。具体语法与可用字段见插件内「出词」页的说明。

---

## 数据存在哪里

所有设置保存在酒馆的用户配置里：

```
data/st_data/default-user/settings.json → extension_settings.huilin_image
```

- 静态锚点：`chars[卡名].cast[角色].fields`
- 服装与动态状态：`chars[卡名].chats[chatId].dyn[角色]`（按聊天分隔）
- 排版模版：`config.templates[模版名]`

备份这个键即可完整迁移；出图归档目录另行设置。

---

## 更新

- 扩展面板中点「更新」；
- 或重新执行一次 Install Extension 覆盖安装；
- 之后**完全重启酒馆**。

版本号同时写在 `manifest.json` 与 `modules/version.js`，两处必须一致。

## 目录结构

```
manifest.json          插件声明（酒馆读取此文件识别插件）
index.js               入口
style.css              样式
modules/               核心逻辑
  backends/            ComfyUI / NovelAI / OpenAI 三种生图渠道
  ui/                  窗口、页签、图库、角色档案等界面
  consistency.js       一致性规则
  appearanceLibrary.js 外貌库
  outfitLibrary.js     服装库
  archive.js           归档
  moss*.js             排版与漫画页版式
```
